### **2. Write Java code to reverse a string while preserving the whitespace.**
```java
public class ReversePreserveWhitespace {
    public static void main(String[] args) {
        String str = "ab c d";
        char[] input = str.toCharArray();
        char[] result = new char[input.length];
        int j = input.length - 1;

        for (int i = 0; i < input.length; i++) {
            if (input[i] == ' ') {
                result[i] = ' ';
            }
        }

        for (int i = 0; i < input.length; i++) {
            if (input[i] != ' ') {
                while (result[j] == ' ') {
                    j--;
                }
                result[j--] = input[i];
            }
        }

        System.out.println(new String(result));
    }
}
```

### **5. What is LinkedHashMap?**
- A `LinkedHashMap` is a hashmap that maintains insertion order.
- Use when you need fast lookups **and** predictable iteration order.

### **6. Explain black-box and white-box testing.**
- **Black-box**: Test without looking at internal code (functional testing).
- **White-box**: Test with knowledge of the internal logic (unit testing, path testing).

---

### **7. Difference between an exception and an error.**
- **Exception**: Recoverable (e.g., FileNotFoundException).
- **Error**: Unrecoverable (e.g., OutOfMemoryError).

---

### **8. Difference between `findElement()` and `findElements()`.**
- `findElement()` returns a single WebElement, throws exception if not found.
- `findElements()` returns a list of WebElements, returns empty list if none found.

---

### **9. Difference between implicit and explicit wait.**
- **Implicit**: Set once globally, applies to all elements.
- **Explicit**: Applied conditionally on specific elements (e.g., `WebDriverWait`).

### **10. Dynamic vs Static Binding**

- **Dynamic Binding**: At runtime (method overriding via inheritance/polymorphism).

### **11. Method Overloading vs Overriding**
- **Overloading**: Same method name, different parameters (compile-time).
- **Overriding**: Subclass modifies a method of superclass (runtime).

### **18. When would you require fluent waits?**
✅ When:
- Web elements load dynamically
- Polling required at regular intervals
```java

  .withTimeout(Duration.ofSeconds(30))
  .pollingEvery(Duration.ofSeconds(5))
  .ignoring(NoSuchElementException.class);
```
