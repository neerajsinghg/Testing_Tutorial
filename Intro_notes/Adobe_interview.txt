### **4. Selenium Questions:**
#### a. **Handle Multiple Windows**
```java
String mainWindow = driver.getWindowHandle();
for(String win : driver.getWindowHandles()){
    if(!win.equals(mainWindow)){
        driver.switchTo().window(win);
    }
}
```

#### b. **Handle Dynamic Dropdowns**
- Use XPath with partial match, or JavaScript click if normal click fails.
```java
driver.findElement(By.xpath("//ul/li[contains(text(),'Option')]")).click();
```

#### c. **Handle Shadow DOM**
- Use `JavascriptExecutor` or Selenium 4's new `getShadowRoot()`:
```java
WebElement shadowHost = driver.findElement(By.cssSelector("#shadow-host"));
SearchContext shadowRoot = shadowHost.getShadowRoot();
shadowRoot.findElement(By.cssSelector("input")).sendKeys("test");
```

### **7. Write Java code to print all permutations of a given string**
✅ Recursive solution:
```java
public class Permutation {
    static void permute(String str, String ans) {
        if(str.length() == 0){
            System.out.println(ans);
            return;
        }
        for(int i=0; i<str.length(); i++){
            char ch = str.charAt(i);
            String ros = str.substring(0, i) + str.substring(i + 1);
            permute(ros, ans + ch);
        }
    }
    public static void main(String[] args){
        permute("abc", "");
    }
}
```

public class StringPermutations {
    public static void main(String[] args) {
        String str = "ABC";
        permute(str, "");
    }
    public static void permute(String str, String result) {
        // Base case
        if (str.length() == 0) {
            System.out.println(result);
            return;
        }
        for (int i = 0; i < str.length(); i++) {
            char current = str.charAt(i);
            // Remaining string after removing current character
            String remaining = str.substring(0, i) + str.substring(i + 1);
            // Recursive call
            permute(remaining, result + current);
        }
    }
}

### **3. Parallel Testing in TestNG + RetryAnalyzer**
- **TestNG Parallel**: Define parallelism in `testng.xml` or `testng.properties`
```xml
<suite name="TestSuite" parallel="tests" thread-count="3">
```
- **RetryAnalyzer**: Retry failed tests
```java
public class Retry implements IRetryAnalyzer {
    private int count = 0, maxTry = 2;
    public boolean retry(ITestResult result) {
        if(count < maxTry) {
            count++;
            return true;
        }
        return false;
    }
}
```

### **4. Singleton Design Pattern + Code**
Ensures only **one instance** of a class is created.
```java
public class Singleton {
    private static Singleton instance;
    private Singleton() {}
    public static Singleton getInstance() {
        if(instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

### **1. Sort array of 0,1,2 in O(n) time (Dutch National Flag Algorithm)**
```java
int low = 0, mid = 0, high = arr.length - 1;
while(mid <= high){
    if(arr[mid] == 0) swap(arr, low++, mid++);
    else if(arr[mid] == 1) mid++;
    else swap(arr, mid, high--);
}
```
