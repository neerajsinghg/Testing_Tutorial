## ✅ **High-Level Overview**

This framework is built for **UI + API test automation** using **Selenium, TestNG, Java, and REST-assured**, with key enterprise features like:

- **Modular and scalable architecture**
- **Cross-browser and parallel execution**
- **Cloud support** (BrowserStack/SauceLabs)
- **Retry analyzer**, **Allure & Extent reporting**
- **CI/CD ready** with **Docker and Jenkins**
- **Data-driven testing** from Excel/JSON
- **BDD support with Cucumber**
- **Database validation (MySQL/Neo4j)**

---

## 🔍 **Folder & Package Breakdown**

### `src/main/java/`

#### 📁 base/
Contains reusable core components to manage browser sessions, retry logic, test listeners, and parallel execution.

- `BaseTest.java` – Base class for all test classes, handles setup/teardown.
- `DriverFactory.java` – Centralized WebDriver instantiation and management.
- `TestListener.java` – TestNG listener for logs, screenshots, and report updates.
- `RetryAnalyzer.java` – Retries failed tests automatically.
- `ParallelTestManager.java` – Manages test data and drivers in parallel mode.
- `WebDriverFactoryManager.java` – Handles driver lifecycle with Thread Local for safety in parallel runs.

---

#### 📁 pages/
Page Object Model (POM) layer to represent each page.

- `LoginPage.java`, `DashboardPage.java`, etc. – Define locators and user actions.
- `CommonPageElements.java` – Contains common elements used across multiple pages like headers/footers.

---

#### 📁 api/
For **REST API testing and integration** with UI tests.

- `ApiHelper.java` – Utility for GET/POST/PUT/DELETE calls using REST-assured.
- `ApiConstants.java` – Stores API endpoint constants.
- `ApiPayloadBuilder.java` – Dynamically creates JSON/XML payloads for requests.
- `ApiValidator.java` – Validates API response structure, schema, and values.

---

#### 📁 db/
Contains database utilities for backend validation.

- `MySQLUtil.java` – Execute SQL queries, validate DB entries.
- `Neo4jUtil.java` – Validate graph DB nodes and relationships.
- `QueryConstants.java` – Central storage for DB query templates.

---

#### 📁 cloud/
Handles remote WebDriver setup and capabilities for cloud platforms.

- `BrowserStackManager.java`, `SauceLabsManager.java` – Initialize drivers with cloud credentials.
- `CloudCapabilities.java` – Set desired capabilities for browser/OS combinations.

---

#### 📁 utils/
Reusable utility classes to support tests.

- `ConfigReader.java` – Loads values from `config.properties`.
- `ExcelUtil.java` – Reads test data from Excel.
- `JSONReader.java` – Loads and parses JSON test data.
- `WaitUtils.java` – Explicit and fluent waits.
- `ScreenshotUtil.java` – Captures screenshots on failure.
- `Log.java` – Centralized logging using Log4j.
- `EmailUtil.java` – Sends test reports over email.
- `ZipUtil.java` – Zips screenshots, logs for archival.
- `SlackNotifier.java` – Sends test status to Slack channel.
- `GitUtil.java` – For Git tagging and versioning after execution.
- `EncryptionUtil.java` – Secures sensitive config like passwords.

---

#### 📁 constants/
Stores constant values used across the framework.

- `AppConstants.java` – Timeouts, page titles, error messages.
- `FrameworkPaths.java` – Paths for reports, drivers, logs, test data.
- `EnvironmentConstants.java` – URLs, API keys per environment.

---

---

### `src/test/java/`

#### 📁 tests/
Contains your TestNG test classes.

- `LoginTest.java`, `DashboardTest.java`, etc. – Implement test cases.
- `ApiTest.java` – For API-only or API+UI hybrid tests.
- `IntegrationTest.java` – For end-to-end flows.
- `PerformanceTest.java` – Hook into JMeter/other tools.
- `DBValidationTest.java` – DB integrity checks.
- `BaseTestHooks.java` – TestNG hooks for before/after test suite/class.

---

### `src/test/resources/`

- `featurefiles/` – Gherkin `.feature` files for Cucumber BDD scenarios.
- `testdata/` – JSON payloads for API and UI tests.
- `locators/` – Optional YAML/XML locator repo for centralized maintenance.

---

### 📁 config/
- `config.properties` – Central config file.
- `environments/qa.properties`, `dev.properties`, etc. – Environment-specific configs (for staging/dev/prod).

---

### 📁 testdata/
Stores all your data sources:

- `loginTestData.xlsx`, `dashboardData.xlsx` – Excel files for UI tests.
- `testData.json` – Common reusable data for tests.
- `payloads/userPayload.json` – API payloads.

---

### 📁 reports/
- `ExtentReport.html` – UI execution report.
- `allure-results/` and `allure-report/` – Allure integration for better tracking and visual analysis.
- `screenshots/` – Failure screenshots.
- `archive/` – Past reports.

---

### 📁 logs/
- `test.log`, `error.log` – Execution and error logs.

---

### 📁 drivers/
- Local WebDriver executables for Chrome, Firefox, Edge, etc.

---

### 📁 resources/
- `log4j2.xml` – Logging configuration.
- `extent-config.xml` – Extent report theming/config.
- `allure.properties` – Metadata for Allure reports.

---

### 📁 build/
- `target/` – Compiled classes.
- `output/` – PDF reports or post-processed outputs.

---

### 📁 ci/
- `Jenkinsfile` – Declarative pipeline script for Jenkins CI/CD.
- `run-tests.sh` – Bash script to run tests in Unix CI agents.
- `generate-allure-report.sh` – Automates Allure report generation.

---

### 📁 docker/
- `Dockerfile` – For running tests in isolated containers.
- `docker-compose.yml` – Runs complete test grid (Selenium Grid + Nodes).

---

### 📁 cloud/
- `BrowserStackConfig.json`, `SauceLabsConfig.json` – Capabilities, credentials, platform matrix.

---

### 🧩 Others

- `maven-profiles/profiles.xml` – Define QA, DEV, UAT profiles for dynamic suite execution.
- `testng.xml` – TestNG suite config.
- `pom.xml` – Maven dependencies, plugins, profiles.
- `README.md` – Setup, usage, commands, structure.
