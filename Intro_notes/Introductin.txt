✅ Explicit Wait Example:

WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

Wait<WebDriver> wait = new FluentWait<>(driver)
    .withTimeout(Duration.ofSeconds(20))          // Total wait time
    .pollingEvery(Duration.ofSeconds(2))          // Poll every 2 seconds
    .ignoring(NoSuchElementException.class);      // Ignore this exception

WebElement element = wait.until(driver -> driver.findElement(By.id("myElement")));

Code to Read Data from Excel Using POI
Here's a simple example of reading an Excel file (.xlsx) using Apache POI:
import org.apache.poi.openxml4j.exceptions.InvalidFormatException;
import org.apache.poi.ss.usermodel.*;

import java.io.File;
import java.io.FileInputStream;
import java.io.IOException;

public class ExcelReader {

    public static void main(String[] args) throws IOException, InvalidFormatException {
        // Path to the Excel file
        FileInputStream file = new FileInputStream(new File("path_to_excel_file.xlsx"));

        // Create Workbook instance for .xlsx file
        Workbook workbook = WorkbookFactory.create(file);

        // Get the first sheet (you can use getSheetAt(index) for other sheets)
        Sheet sheet = workbook.getSheetAt(0);

        // Iterate through all rows
        for (Row row : sheet) {
            // Iterate through all columns of the current row
            for (Cell cell : row) {
                // Check the cell type and print the corresponding value
                switch (cell.getCellType()) {
                    case STRING:
                        System.out.print(cell.getStringCellValue() + "\t");
                        break;
                    case NUMERIC:
                        System.out.print(cell.getNumericCellValue() + "\t");
                        break;
                    case BOOLEAN:
                        System.out.print(cell.getBooleanCellValue() + "\t");
                        break;
                    default:
                        System.out.print("Unsupported Cell Type\t");
                        break;
                }
            }
            System.out.println(); // Move to the next line after each row
        }

        // Close the workbook
        workbook.close();
        file.close();
    }
}

38. Write code to write results in excel sheet.

import org.apache.poi.ss.usermodel.*;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import java.io.FileOutputStream;
import java.io.IOException;

public class ExcelWriter {
    public static void main(String[] args) throws IOException {
        // Create a workbook and a sheet
        Workbook workbook = new XSSFWorkbook();
        Sheet sheet = workbook.createSheet("Test Results");

        // Create a header row
        Row headerRow = sheet.createRow(0);
        headerRow.createCell(0).setCellValue("Test Case ID");
        headerRow.createCell(1).setCellValue("Description");
        headerRow.createCell(2).setCellValue("Status");

        // Sample test results
        Object[][] testData = {
            {"TC_01", "Login Test", "Passed"},
            {"TC_02", "Add to Cart Test", "Failed"},
            {"TC_03", "Checkout Test", "Passed"}
        };

        // Write data to the sheet
        int rowNum = 1;
        for (Object[] data : testData) {
            Row row = sheet.createRow(rowNum++);
            for (int i = 0; i < data.length; i++) {
                row.createCell(i).setCellValue(data[i].toString());
            }
        }

        // Auto-size columns
        for (int i = 0; i < 3; i++) {
            sheet.autoSizeColumn(i);
        }

        // Write to file
        FileOutputStream fileOut = new FileOutputStream("TestResults.xlsx");
        workbook.write(fileOut);
        fileOut.close();
        workbook.close();

        System.out.println("Excel file created successfully!");
    }
}

Agar tu kisi app, website, ya system ka testing kar raha hai — toh kuch **basic to advanced cheezein** chahiye hoti hain testing start karne ke liye.

Let’s break it down 👇

---

## 🧪 🔍 **Requirements for Testing** (Manual + Automation)

### ✅ **1. Business Requirements / Functional Specs**
- *Kya app ka purpose hai?*
- *User kya karega?*  
- Milta hai: **BRD**, **FRS**, user stories (Jira, Confluence, etc.)

🔸 **Example**:  
> "User should be able to log in with email and password"

---

### ✅ **2. Test Data**
- Valid/Invalid inputs for testing
- User credentials, dummy cards, test API keys etc.

---

### ✅ **3. Environment Access**
- Dev / QA / Staging / UAT
- Test environment should match production setup as close as possible

---

### ✅ **4. Build/Application**
- `.apk` / `.ipa` for mobile  
- URL or WAR file for web  
- Should be deployable for testing

---

### ✅ **5. Test Scenarios / Test Cases**
- Manual: Written test cases  
- Automation: Defined flow or scripts

🧾 Example:
- TC001: Login with valid credentials  
- TC002: Login with wrong password

---

### ✅ **6. Tools & Setup**
For automation, you’ll need:
- ✅ Java / Python / JS setup
- ✅ Selenium / Appium / Cypress / Playwright
- ✅ TestNG / JUnit
- ✅ Maven / Gradle
- ✅ Git repo
- ✅ Jenkins for CI/CD

---

### ✅ **7. Access to Logs & Debugging**
- App logs, browser console, server logs
- Helpful in debugging failed tests

---

### ✅ **8. Device/Browser Matrix**
- Browser versions (Chrome, Firefox, Safari)  
- Mobile devices (Android, iOS, tabs)  
- Emulator/Simulator or real device (or cloud platforms like BrowserStack, SauceLabs)

---

### ✅ **9. APIs or Backend Info (if needed)**
- API request/response
- Postman collections, Swagger documentation

---

### ✅ **10. Team Collaboration Tools**
- Jira (for bug reporting)  
- Confluence (for docs)  
- Slack/MS Teams (for discussion)

---

## 💡 Extra for Automation Testing:

- Framework (POM, Keyword, Hybrid)
- Reporting (Extent, Allure)
- Logging (Log4j or SLF4J)
- Retry mechanism
- Screenshots on failure
- Integration with DB, APIs, etc.

---

## 🧠 Short Answer for Interview:

> “For effective testing, I require proper documentation (like BRD/FRS), test data, a stable environment, access to the application build, and the right tools like Selenium/Appium, TestNG, and reporting tools. For automation, a well-structured framework with CI/CD integration is essential.”
