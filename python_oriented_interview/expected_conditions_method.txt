In **Python Selenium with pytest**, `ExpectedConditions` are available inside:

```python
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.support.ui import WebDriverWait
```

Below is the **Python equivalent syntax** of the commonly used `ExpectedConditions`.

---

# ✅ 1. Title Related Conditions

```python
EC.title_is("Dashboard")
EC.title_contains("Dash")
```

---

# ✅ 2. URL Related Conditions

```python
EC.url_to_be("https://example.com/home")
EC.url_contains("home")
EC.url_matches(".*home.*")
```

---

# ✅ 3. Element Presence / Visibility

```python
EC.presence_of_element_located((By.ID, "username"))
EC.visibility_of_element_located((By.ID, "username"))
EC.visibility_of(element)
EC.visibility_of_all_elements_located((By.TAG_NAME, "a"))
EC.visibility_of_all_elements(elements)
EC.presence_of_all_elements_located((By.CLASS_NAME, "item"))
```

---

# ✅ 4. Element Clickable / Selected

```python
EC.element_to_be_clickable((By.ID, "login"))
EC.element_to_be_clickable(element)

EC.element_to_be_selected(element)
EC.element_located_to_be_selected((By.ID, "checkbox"))

EC.element_selection_state_to_be(element, True)
EC.element_located_selection_state_to_be((By.ID, "checkbox"), True)
```

---

# ✅ 5. Text Related Conditions

```python
EC.text_to_be_present_in_element(element, "Success")
EC.text_to_be_present_in_element((By.ID, "msg"), "Success")

EC.text_to_be_present_in_element_value(element, "Admin")
EC.text_to_be_present_in_element_value((By.ID, "username"), "Admin")
```

---

# ✅ 6. Frame Conditions

```python
EC.frame_to_be_available_and_switch_to_it(0)
EC.frame_to_be_available_and_switch_to_it("frameName")
EC.frame_to_be_available_and_switch_to_it((By.ID, "frame1"))
EC.frame_to_be_available_and_switch_to_it(frame_element)
```

---

# ✅ 7. Alert Condition

```python
EC.alert_is_present()
```

---

# ✅ 8. Window Conditions

```python
EC.number_of_windows_to_be(2)
EC.new_window_is_opened(current_handles)
```

---

# ✅ 9. Invisibility Conditions

```python
EC.invisibility_of_element(element)
EC.invisibility_of_element_located((By.ID, "loader"))
```

---

# ✅ 10. Staleness Condition

```python
EC.staleness_of(element)
```

Used when page refreshes and old element becomes stale.

---

# ✅ 11. Attribute Conditions (Selenium 4)

```python
EC.text_to_be_present_in_element_attribute((By.ID, "input"), "value", "Admin")
```

For custom attribute checking, usually lambda is used:

```python
WebDriverWait(driver, 10).until(
    lambda d: d.find_element(By.ID, "btn").get_attribute("class") == "active"
)
```

---

# ✅ 12. DOM Property Conditions (Custom in Python)

Python does not provide direct methods for all Java DOM conditions, so use lambda:

```python
WebDriverWait(driver, 10).until(
    lambda d: d.find_element(By.ID, "field").get_dom_attribute("value") == "123"
)
```

# ✅ Complete Example in Pytest

```python
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

def test_login(driver):
    wait = WebDriverWait(driver, 10)

    username = wait.until(
        EC.visibility_of_element_located((By.ID, "username"))
    )
    username.send_keys("admin")

    password = wait.until(
        EC.visibility_of_element_located((By.ID, "password"))
    )
    password.send_keys("123456")

    login_btn = wait.until(
        EC.element_to_be_clickable((By.ID, "login"))
    )
    login_btn.click()

    wait.until(EC.title_contains("Dashboard"))
```
