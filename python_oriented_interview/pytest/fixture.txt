Pytest provides several built-in fixtures like request, tmp_path, pytestconfig, and cache, which I commonly use in Selenium frameworks for runtime configuration, reporting, and managing temporary execution data.

| Fixture           | Purpose                     | How I use it in real framework                            |
| ----------------- | --------------------------- | --------------------------------------------------------- |
| `request`         | Gives current test context  | For dynamic screenshot naming and accessing test metadata |
| `pytestconfig`    | Reads runtime configuration | To get browser, environment, URLs from CLI                |
| `tmp_path`        | Temporary file path         | Save screenshots, logs, downloaded files                  |
| `cache`           | Store data between runs     | Save tokens/session values                                |
| `monkeypatch`     | Modify values temporarily   | Override env variables during testing                     |
| `capsys`          | Capture console output      | Validate logs/debugging                                   |
| `record_property` | Add report data             | Add custom details to reports                             |
