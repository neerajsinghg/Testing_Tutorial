✅ WebDriver Properties
| Property                       | Description                                    |
| ------------------------------ | ---------------------------------------------- |
| `driver.title`                 | Returns the title of the current webpage       |
| `driver.current_url`           | Returns the current page URL                   |
| `driver.page_source`           | Returns complete HTML source of the page       |
| `driver.name`                  | Returns browser name such as chrome or firefox |
| `driver.session_id`            | Returns unique browser session ID              |
| `driver.capabilities`          | Returns browser capabilities/settings          |
| `driver.window_handles`        | Returns list of all open window handles        |
| `driver.current_window_handle` | Returns current active window handle           |
| `driver.switch_to`             | Used to switch to alert, frame, or window      |

✅ switch_to Related Properties
| Property                          | Description                       |
| --------------------------------- | --------------------------------- |
| `driver.switch_to.alert`          | Returns current alert object      |
| `driver.switch_to.active_element` | Returns currently focused element |

✅ WebElement Properties
| Property                    | Description                               |
| --------------------------- | ----------------------------------------- |
| `element.text`              | Returns visible text of element           |
| `element.tag_name`          | Returns HTML tag name of element          |
| `element.size`              | Returns element width and height          |
| `element.location`          | Returns x and y coordinates               |
| `element.rect`              | Returns size + location in one dictionary |
| `element.accessible_name`   | Returns accessibility name                |
| `element.aria_role`         | Returns ARIA role of element              |
| `element.screenshot_as_png` | Returns screenshot bytes of element       |

✅ Alert Property
| Property     | Description                           |
| ------------ | ------------------------------------- |
| `alert.text` | Returns text message from alert popup |


✅ Example
print(driver.title)
print(driver.current_url)
print(element.text)
