## AUTOMATION RULES

1. Always wait for page readiness before interaction.
2. Use explicit waits instead of static sleeps.
3. Capture screenshot on every failure.
4. Log every major action.
5. Retry flaky actions up to 3 times.
6. Never expose passwords/tokens in logs.
7. Use environment variables for credentials.
8. Never execute destructive production actions without confirmation.
9. Validate page title or unique element after navigation.
10. Prefer stable locators:

* ID
* data-testid
* name
* aria-label
  Avoid fragile XPath whenever possible.

## SECURITY REQUIREMENTS

STRICTLY FOLLOW:

1. Never store credentials in plain text.
2. Never expose internal URLs externally.
3. Never send sensitive enterprise data to public APIs.
4. Mask confidential information in logs.
